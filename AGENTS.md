# AGENTS.md
Ayuda para scripts `bash` y `batch`. Los scripts serán para generar prompts ordenados y legibles, utilizando plantillas de prompts.

- Recordar usar namespace tipo `bash` para bash scripts.
- Recordar usar namespace tipo `batch` para batch scripts.
- Recordar dar prioridad a hacer plantillas markdown.
- Es normal que existan `bash` y `batch` scripts con el mismo nombre.
